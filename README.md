# Elarion Music Control

Лёгкий игровой оверлей для управления настольным приложением Яндекс Музыки без Alt+Tab.

Автор: **BRAT12344321**

Версия: **4.0.0**

Поддержка: **@kt1w_X**

## Возможности

- системные горячие клавиши `RegisterHotKey`, которые забирают только готовую комбинацию и не
  перехватывают одиночный Shift;
- управление именно медиасессией Яндекс Музыки через Windows Media Control;
- небольшой HUD с обложкой, названием трека, громкостью и перемоткой;
- отдельная подсказка со всеми сочетаниями клавиш;
- тёмный liquid-glass интерфейс с размытым реальным фоном строго внутри физической скруглённой маски;
- округлённая маска окна без непрозрачных углов;
- корректная работа на мониторе, где находится активная игра;
- событийная синхронизация трека и редкий резервный опрос без частых topmost-таймеров;
- защита от повторного запуска и ротация небольшого диагностического журнала;
- караоке с точным 60-FPS таймером, кэшем разметки и безопасной поправкой синхронизации с шагом 0,10 с;
- переключатель четырёх запрошенных вариантов: Grechka SHA, Boingster, Grunge SHA и Sour Gummy;
  отсутствующий локальный файл явно помечается, а безопасным резервным шрифтом остаётся Wix Madefor;
- мастер первого запуска и настройки из системного трея: внешний вид, караоке и все 16 сочетаний клавиш;
- четыре компактных режима караоке, выбор 30/60/90 FPS и экономичный таймер при паузе;
- независимый масштаб каждого GUI колёсиком мыши в режиме перемещения с сохранением позиции и размера;
- умное появление и полноэкранный режим, подавляющие только автоматические карточки трека во время игры;
- автоматический pass-through в Minecraft и полноэкранных приложениях: оверлей выполняет команду, но Tab, Shift и остальные клавиши одновременно продолжают поступать в игру.
- адаптивная проверка игрового окна: 4 раза в секунду во время игры и 1 раз в секунду в обычном рабочем столе;
- безопасный перенос настроек, кэша текста и пользовательских шрифтов с версии 3.5.5.

## Запуск

Подробная инструкция для первого запуска, проверки и сборки находится в
[`docs/BEGINNER_GUIDE.md`](docs/BEGINNER_GUIDE.md).

Быстрая подготовка исходников:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup-dev.ps1
.\run-dev.ps1
```

Ручной запуск после установки зависимостей:

```powershell
pythonw.exe yandex_music_overlay.pyw
```

Приложение не показывает главное окно. Для проверки нажмите `Ctrl + Shift + K`.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| Ctrl + Shift + X | Следующий трек |
| Ctrl + Shift + Z | Предыдущий трек |
| Ctrl + Shift + C | Пауза / воспроизведение |
| Ctrl + Shift + ← / → | Перемотка на 10 секунд |
| Ctrl + Shift + ↑ / ↓ | Громкость аудиосессии Яндекс Музыки в микшере Windows |
| Ctrl + Shift + M | Выключить / включить звук |
| Ctrl + Shift + O | Включить / выключить уведомления |
| Ctrl + Shift + L | Караоке |
| Ctrl + Shift + K | Показать / скрыть подсказку |
| Ctrl + Shift + H | Запустить Яндекс Музыку |
| Ctrl + Shift + F | Сменить доступный шрифт |
| Shift + Tab | Показать текст позже на 0,10 секунды |
| Ctrl + Shift + Tab | Показать текст раньше на 0,10 секунды |
| Ctrl + Shift + G | Включить режим перемещения HUD мышью |

Открытая подсказка закрывается клавишей `Esc`. В режиме `Ctrl + Shift + G` одновременно показываются
карточка трека, отдельное окно караоке и подсказка; каждое окно перемещается и сохраняет позицию отдельно.
Клавиши `Х` и `Ъ` больше не используются для караоке.

Дополнительные `.ttf` и `.otf` загружаются из
`%LOCALAPPDATA%\ElarionMusicControl\fonts`. При обновлении с версии 3.5.5 настройки, кэш текста и
пользовательские шрифты переносятся автоматически. Предоставленные локальные копии всех четырёх шрифтов
уже подключены на этом компьютере. В публичный архив входят только шрифты, лицензия которых разрешает
распространение; Grechka SHA, Boingster и Grunge SHA требуют отдельного разрешения правообладателей.

При наличии переменной окружения `YANDEX_MUSIC_TOKEN` приложение сначала запрашивает синхронный LRC
непосредственно у Яндекс Музыки. Токен читается только в память процесса, не записывается в настройки и
не попадает в журнал. Без него используется LRCLIB и резервная примерная синхронизация обычного текста.

## Совместимость

Windows 10/11, Python 3.11+, настольное приложение Яндекс Музыки. HUD рассчитан на оконный и
полноэкранный безрамочный режим. В эксклюзивном полноэкранном режиме некоторые игры получают
монопольный вывод поверх DWM; для гарантированного отображения следует выбрать безрамочный режим.

Регулятор громкости изменяет только отдельную аудиосессию Яндекс Музыки в микшере Windows. Внутренний
ползунок самого приложения является частью закрытого Electron-плеера и не предоставляет поддерживаемой
внешней команды, поэтому его положение может не совпадать с уровнем Windows.
