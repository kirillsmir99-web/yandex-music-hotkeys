# Yandex Music Overlay & Hotkeys v2.0.0

Кастомный виджет и глобальные горячие клавиши для управления **Яндекс Музыкой** на Windows в стиле **Liquid Glass**.

## 🌟 Основные возможности

- **🎤 Режим Караоке (`Ctrl + Shift + L`)**:
  - Плавное анимированное раскрытие плашки уведомления с синхронизированным текстом песни (LRC).
  - Миллисекундная синхронизация с воспроизведением в реальном времени.
  - Плавные эффекты всплытия текста (`QGraphicsOpacityEffect` + `OutCubic`).
  - Подсветка текущей строчки золотистым неоновым стилем.
- **🧭 Меню горячих клавиш (`Ctrl + Shift + K`)**:
  - Стеклянная панель в стиле Fluent Glass с подсказками по клавишам.
- **⚡ Нулевая задержка в играх (Zero Input Lag)**:
  - Обработка нажатий через несокрушающий перехват без задержек для клавиатур в играх.
- **🔄 Авто-отслеживание треков**:
  - Автоматически обновляет плашку и загружает текст при смене песни.

## ⌨️ Горячие клавиши

| Горячие клавиши | Действие |
|---|---|
| `Ctrl + Shift + X` | Следующий трек |
| `Ctrl + Shift + Z` | Предыдущий трек |
| `Ctrl + Shift + C` | Пауза / Воспроизведение |
| `Ctrl + Shift + ← / →` | Перемотка ±10 секунд |
| `Ctrl + Shift + ↑ / ↓` | Громкость выше / ниже |
| `Ctrl + Shift + M` | Выключить звук (Mute) |
| `Ctrl + Shift + O` | Включить / выключить уведомления |
| `Ctrl + Shift + L` | **Режим Караоке / Текст песни** |
| `Ctrl + Shift + K` | Показать / скрыть меню справки |
| `Ctrl + Shift + H` | Запустить Яндекс Музыку |

## 🚀 Установка и запуск

1. Убедитесь, что установлен Python 3.10+ и зависимости:
   ```bash
   pip install PyQt6 winsdk pycaw keyboard
   ```
2. Запустите скрипт:
   ```bash
   pythonw yandex_music_hotkeys.pyw
   ```
