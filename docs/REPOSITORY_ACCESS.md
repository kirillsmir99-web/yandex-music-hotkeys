# Доступ к закрытому репозиторию

Покупка включает снимок исходников и доступ к закрытому репозиторию с готовыми Windows-сборками и обновлениями.

1. Открой ссылку из персонального файла `REPOSITORY-ACCESS.txt`, полученного после покупки.
2. Напиши в поддержку @kt1w_X свой GitHub username и номер заказа.
3. Прими приглашение GitHub на доступ к приватному репозиторию.
4. Не пересылай приглашение, ссылку и исходники другим людям.

Одна покупка выдаёт доступ одному GitHub-аккаунту. При смене аккаунта поддержка сначала отзывает старое
приглашение, затем добавляет новое. Сам URL не является защитой: репозиторий остаётся приватным, а доступ
проверяет GitHub.

Покупательский архив сразу содержит полный снимок исходников приобретённой версии. Готовый EXE скачивается
из раздела Releases после принятия приглашения. Это разделение необходимо, потому что корректная PySide6-сборка
превышает стандартный лимит 49 МБ у Telegram Bot API.
