# Код и готовые сборки на GitHub

Elarion Music Control распространяется с открытым исходным кодом под MIT License.

1. Открой страницу проекта на GitHub.
2. Нажми `Code` → `Download ZIP`, чтобы скачать исходники без Git.
3. Для готовой Windows-версии открой `Releases` и выбери последний стабильный релиз.
4. Скачай `ElarionMusicControl.exe` и соседний файл `.sha256`.
5. Сверь контрольную сумму перед первым запуском.

Аккаунт GitHub, приглашение и лицензионный ключ не нужны. Код можно использовать, изменять и
распространять при сохранении текста MIT License и уведомлений сторонних компонентов.

Не добавляй в публичный fork токены, cookies, личные настройки и журналы пользователя.
