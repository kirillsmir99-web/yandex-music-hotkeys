# Руководство пользователя Elarion Music Control

## Установка

1. Установи официальное настольное приложение Яндекс Музыки для Windows.
2. Распакуй архив Elarion Music Control в отдельную папку.
3. Запусти `ElarionMusicControl.exe`.
4. В мастере первого запуска проверь сочетания клавиш и нужные режимы.
5. Включи трек в Яндекс Музыке и нажми `Ctrl + Shift + K`.

Приложение работает из системного трея и не требует постоянно открытого главного окна. Автозапуск,
внешний вид, караоке и сочетания клавиш меняются через пункт «Настройки» в меню значка рядом с часами.

## Основное управление

| Сочетание | Результат |
|---|---|
| `Ctrl + Shift + X` | следующий трек |
| `Ctrl + Shift + Z` | предыдущий трек |
| `Ctrl + Shift + C` | пауза или воспроизведение |
| `Ctrl + Shift + ←/→` | перемотка на 10 секунд |
| `Ctrl + Shift + ↑/↓` | громкость только Яндекс Музыки |
| `Ctrl + Shift + M` | выключение звука |
| `Ctrl + Shift + O` | уведомления о треках |
| `Ctrl + Shift + L` | караоке |
| `Ctrl + Shift + K` | подсказка |
| `Ctrl + Shift + H` | запуск Яндекс Музыки |
| `Ctrl + Shift + F` | следующий доступный шрифт |
| `Shift + Tab` | текст караоке позже |
| `Ctrl + Shift + Tab` | текст караоке раньше |
| `Ctrl + Shift + G` | перемещение и масштабирование HUD |

Любое сочетание можно заменить в настройках. Программа не сохранит конфликтующие комбинации.

## Игровой режим

В полноэкранном или безрамочном приложении Elarion автоматически использует pass-through: выполняет
музыкальную команду, но не забирает обычные Shift, Tab и другие клавиши у игры. Для наиболее стабильного
отображения HUD используй безрамочный полноэкранный режим.

## Караоке

Синхронный текст сначала ищется через доступный источник, затем сохраняется в локальный кэш. Если точных
временных меток нет, приложение создаёт приблизительную разметку и явно отмечает её. Поправка
синхронизации ограничена диапазоном от -1,50 до +1,50 секунды.

## Данные и приватность

Настройки находятся в реестре текущего пользователя, а журнал, кэш текста и дополнительные шрифты — в
`%LOCALAPPDATA%\ElarionMusicControl`. Приложение не отправляет журнал разработчику автоматически.
Не публикуй журнал без проверки: в нём могут находиться названия треков и технические сведения о запуске.

## Удаление

Закрой приложение через системный трей, удали EXE и при необходимости папку
`%LOCALAPPDATA%\ElarionMusicControl`. Параметры реестра можно оставить: они не запускают фоновые процессы.
