# Решение проблем

## Подсказка не появилась

Проверь значок Elarion в системном трее и нажми `Ctrl + Shift + K`. Если значка нет, открой
`%LOCALAPPDATA%\ElarionMusicControl\overlay.log` и отправь в поддержку последние строки без токенов и
личных данных.

## Команды не переключают музыку

Запусти настольное приложение Яндекс Музыки, включи трек и проверь системный медиа-виджет Windows.
Elarion управляет официальной Windows Media Session, а не веб-страницей браузера.

## HUD не виден поверх игры

Выбери в игре безрамочный полноэкранный режим. Эксклюзивный fullscreen может получать монопольный вывод
поверх DWM и скрывать сторонние окна.

## Горячая клавиша не регистрируется

Открой настройки и назначь другую комбинацию. Windows или другая программа могла занять выбранную
клавишу. Elarion показывает число успешно зарегистрированных комбинаций в журнале.

## Караоке спешит или отстаёт

Измени поправку в настройках шагом 0,10 секунды. Кнопка сброса возвращает +0,15 секунды. Для некоторых
треков источник предоставляет только обычный текст — в этом случае синхронизация будет приблизительной.

## Высокая нагрузка

Закрой лишние копии приложения и отключи 90 FPS для караоке. В состоянии паузы караоке автоматически
переходит на экономичный таймер, а проверка игрового окна в обычном рабочем столе выполняется раз в
секунду.
