# Руководство для новичка

Это исходники игрового оверлея для настольного приложения Яндекс Музыки. Оверлей работает в фоне,
реагирует на глобальные сочетания клавиш и показывает небольшие окна поверх игры.

## Что понадобится

1. Windows 10 или Windows 11.
2. Установленное настольное приложение Яндекс Музыки.
3. Python 3.11 x64 с сайта [python.org](https://www.python.org/downloads/).
4. При установке Python включите пункт `Add Python to PATH`.

Другие версии Python могут работать, но проект проверяется на Python 3.11.

## Первый запуск из исходников

Откройте папку проекта в Проводнике. Нажмите правой кнопкой мыши по свободному месту и выберите
«Открыть в терминале». Затем выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup-dev.ps1
.\run-dev.ps1
```

Первый запуск `setup-dev.ps1` создаёт отдельную папку `.venv` и устанавливает зависимости только для
этого проекта. Он не заменяет системные библиотеки Python.

У приложения нет большого главного окна. После запуска оно появляется в системном трее рядом с часами.
Нажмите `Ctrl + Shift + K`, чтобы открыть подсказку с клавишами.

## Как устроен проект

| Путь | Назначение |
|---|---|
| `yandex_music_overlay.pyw` | Точка запуска приложения |
| `ym_overlay/app.py` | Запуск компонентов, трей, настройки и обработка команд |
| `ym_overlay/media.py` | Работа с медиасессией Яндекс Музыки через Windows |
| `ym_overlay/lyrics.py` | Получение, кэширование и разбор синхронного текста |
| `ym_overlay/ui.py` | Карточка трека, караоке, анимации и перемещение окон |
| `ym_overlay/windows.py` | Горячие клавиши, pass-through и системные функции Windows |
| `ym_overlay/settings_ui.py` | Окно настроек и мастер первого запуска |
| `ym_overlay/config.py` | Название, автор, клавиши, цвета и постоянные значения |
| `assets/` | Иконка, метаданные EXE и лицензированные шрифты |
| `tests/` | Автоматические проверки основной логики |
| `tools/` | Проверка интерфейса, углов, клавиш и создание превью |
| `legacy/` | Старые версии, оставленные только для истории |

## Как проходит команда

Например, при нажатии клавиши следующего трека:

1. `windows.py` замечает полное сочетание, не блокируя одиночные Shift или Tab в игре.
2. `app.py` переводит сочетание в команду `next`.
3. `media.py` отправляет команду активной медиасессии Яндекс Музыки.
4. Windows сообщает новые данные трека.
5. `ui.py` обновляет обложку, название и караоке.

Караоке получает текущую позицию из `media.py`. `lyrics.py` ищет временные метки, сохраняет результат в
локальный кэш, а `ui.py` выбирает нужную строку на каждом кадре. Ручная поправка синхронизации хранится в
настройках Windows и ограничена безопасным диапазоном.

## Проверка изменений

Перед сборкой выполните:

```powershell
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q ym_overlay tests
$env:PYTHONPATH='.'
$env:QT_QPA_PLATFORM='offscreen'
.\.venv\Scripts\python.exe tools\smoke_ui.py
```

Ожидаемый результат: Ruff без ошибок, все тесты пройдены, а smoke-проверка заканчивается строкой
`ui_smoke=ok`.

## Сборка EXE

После настройки среды выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1
```

Готовый файл появится в `dist\YandexMusicGameOverlay.exe`. Сборка не устанавливает приложение и не
заменяет уже установленную копию.

## Где хранятся настройки

- параметры приложения: `HKEY_CURRENT_USER\Software\BRAT12344321\YandexMusicGameOverlay`;
- журнал: `%LOCALAPPDATA%\YandexMusicGameOverlay\overlay.log`;
- дополнительные пользовательские шрифты: `%LOCALAPPDATA%\YandexMusicGameOverlay\fonts`.

Не добавляйте токены, журналы, `.venv`, папки `build` и `dist` в Git. Они исключены через `.gitignore`.

## Если что-то не работает

### PowerShell запрещает запуск скриптов

Выполните `Set-ExecutionPolicy -Scope Process Bypass`. Изменение действует только в текущем терминале.

### Подсказка не появляется

Проверьте значок приложения в трее и журнал `overlay.log`. Если запущены две копии, оставьте одну.

### Яндекс Музыка не реагирует

Запустите настольное приложение, включите любой трек и убедитесь, что Windows показывает его в системном
медиа-виджете.

### Караоке отстаёт

Откройте настройки из трея и измените «Синхронизация» шагом 0,10 секунды. Положительное значение показывает
текст раньше, отрицательное — позже. Кнопка «Сбросить» возвращает рекомендуемое значение `+0,15 с`.

### Не найден текст

У разных источников может отличаться название трека или длительность. Для прямого запроса Яндекс Музыки
можно перед запуском задать переменную `YANDEX_MUSIC_TOKEN`. Никогда не записывайте токен в исходники и не
публикуйте его в GitHub.
